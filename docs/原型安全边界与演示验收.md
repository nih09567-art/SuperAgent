# 原型安全边界与演示验收

本文档说明 SuperAgent 执行引擎（TaskGraph 调度 + Artifact 数据协作 + 权限治理）在**原型阶段**的安全边界、已实现的治理机制，以及可离线复现的演示验收标准。

## 1. 原型范围声明

> 原型通过 **Artifact 所有权、S-ABAC、敏感级别、审计、校验和及存储隔离**验证权限治理机制。**静态加密、正式身份认证和生产级密钥管理不在本阶段范围内。**

本轮明确**不做**：

- AES-GCM 静态加密（列为生产化增强项，见 §5）
- HMAC 过渡加密
- Windows ACL 专用实现
- 真实身份认证系统
- 公网 / 生产部署

所有开发与演示仅使用**虚构数据**（如虚构员工「王强」与模拟工资），不含任何真实个人信息或薪资。

## 2. 特性开关

代码缺省值与原型模板推荐值有意分开：无环境配置时保持安全关闭；复制 `.env.example` 启动原型时显式开启已经过治理的 S-ABAC 与调度器路径。

| 层级 | `S_ABAC_ENABLED` | `ORCHESTRATION_SCHEDULER_ENABLED` | `ARTIFACT_CAPTURE_ENABLED` |
|---|---:|---:|---:|
| 代码缺省安全基线 | `false` | `false` | `false` |
| 原型 `.env.example` 推荐配置 | `true` | `true` | `false` |

`ARTIFACT_CAPTURE_ENABLED` 仅控制旧 `publisher/while` 路径的兼容捕获，目前仍关闭。调度器 runtime 独立完成受保护的 Artifact payload 持久化与脱敏 checkpoint 索引，不依赖该旧路径开关。

CLI 的 `run-l`、`run-p`、`resume` 默认使用已注册的演示身份 `admin`；
也可通过 `--user-id` 显式选择 `hr_manager` 等演示用户。未知身份在
S-ABAC 开启时仍然失败关闭。

只读失败恢复相关开关 `SCHEDULER_REDISPATCH_ENABLED`、`SCHEDULER_RETRY_DELAY_SECONDS` 默认关闭 / 为 `0`，详见 §3.5「有界失败恢复」。

新增 Artifact 保护存储配置（见 `.env.example`）：

```dotenv
ARTIFACT_PAYLOAD_STORE_DIR=store/artifacts
ARTIFACT_PAYLOAD_TTL_SECONDS=604800
ARTIFACT_AUDIT_LOG=store/audit/artifact_access.jsonl
```

## 3. 已实现的治理机制

### 3.1 Artifact 数据协作
- 调度器路径中，每个成功步骤的执行结果被捕获为强类型 `Artifact`，携带 `artifact_id`、`version`、`owner_user_id`、`producer_agent_id`、`sensitivity`、`checksum`、`derived_from`（血缘）。
- 步骤间通过 `ArtifactRef` 传递；消费步骤经统一读取路径解析：
  `ArtifactRef → ArtifactResolver → PolicyEngineArtifactGuard → 返回 payload 或拒绝`。
- 敏感级别按「任务风险 与 上游血缘」取最大值。

### 3.2 权限治理（fail-closed）
调度器为每个 `TaskStep` 构造独立安全画像：优先使用步骤声明的
`required_capabilities`、`scenario_tags`、`operation_mode`、`data_scope`
和 `risk_level`；旧计划缺少可选的能力或标签时，才从受信
`RESOURCE_SECURITY_ATTRIBUTES` 补齐。全局画像只保留业务目标和数据范围等
任务上下文，不能覆盖当前步骤的目标域；步骤风险也不能降低全局风险。

以下情况一律拒绝（读取路径失败关闭）：
- 缺少用户身份（subject）。
- 跨用户访问且未在 `allowed_reader_ids` 授权（所有权闸；在 PolicyEngine 之前判定，因为策略引擎无法表达 `subject.id == object.owner_user_id`）。
- S-ABAC 关闭时读取 `confidential`/`restricted` 数据。
- Artifact 缺失或校验和不匹配。
- 未知/未分类操作类型。
- 关键持久化（checkpoint / payload 落盘）失败。

治理式协作：生产步骤可声明 `allowed_reader_ids`，实现**受治理的**跨用户共享（而非一律拒绝）。生产环境该名单须来自可信来源，而非未受信的 Planner 输出。

### 3.3 持久化与恢复
- 调度器提交顺序：**保存 Artifact payload → 保存脱敏 checkpoint 索引 → 标记步骤完成**（任一失败则步骤不判成功；副作用步骤转 `needs_reconciliation`）。
- 调度器 payload 存于受保护的 per-task 目录，与通用 checkpoint 隔离；checkpoint 仅保留脱敏索引（refs + checksum + logical_name + sensitivity），**不含 payload 正文**。
- 恢复时对 payload 做校验和核对，缺失或被修改则失败关闭（`artifact_store_corruption`）。
- 副作用步骤经**原子回执抢占**（跨进程文件锁）保证至多执行一次；已完成步骤恢复后不重复执行；写/发送操作携带幂等键。

### 3.4 审计
- 每次 Artifact 读取的允许/拒绝决策写入持久化审计日志（`ARTIFACT_AUDIT_LOG`）。
- 审计记录**仅元数据**（subject、logical_name、sensitivity、owner、decision、reason、cross_user 标志），**绝不含 payload 或 URI**。

### 3.5 有界失败恢复
- 自动恢复仅适用于 `operation_mode=read` 的只读步骤；写入、发送等副作用步骤不自动重试或改派。
- `FailureDescriptor.retryable=false` 时立即终止；`retryable=true` 且步骤声明重试预算时，同一 Agent 最多重试一次。
- `SCHEDULER_REDISPATCH_ENABLED=true` 时，同 Agent 重试耗尽后最多改派一次；默认关闭。
- 改派会排除已失败 Agent，并在执行前重新检查授权、可信 Agent Contract、输入名称/Schema/cardinality/required 等价性、输出 Schema 兼容性和必需输入。
- 无结构化瞬态信号的旧式 `ExecuteResult.FAILED` 默认不可重试、不可改派；只有平台明确分类的超时等瞬态错误，或适配器验证后的 `result_retryable=true`，才能进入自动恢复。
- 首次尝试、同 Agent 重试和改派分别记录 `attempt`、`phase`、`planned_agent`、`executed_agent`；Skill 证据归属实际执行者。
- 改派不修改 TaskGraph、依赖关系或 PlanSnapshot；运行时二次路由产生的澄清/拒绝只终止恢复，不触发新的全局澄清。
- 单次 Scheduler 运行最多为“首次执行 + 同 Agent 重试一次 + 改派一次”。恢复预算暂不写入 checkpoint，崩溃恢复后会重置；由于仅限只读步骤，原型阶段接受该行为，但不宣称工作流生命周期全局有界。
- `SCHEDULER_RETRY_DELAY_SECONDS` 是同 Agent 重试前的固定等待时间，默认 `0`；本阶段不实现指数退避、对账重放或子图重规划。

## 4. 安全表述的准确边界

- **SHA-256 校验和**仅用于发现**意外损坏与简单修改**，**不能宣称密码学防篡改**（能改写 payload 的攻击者也能重算校验和）。
- 存储目录的 `chmod(0700)` 是 **best-effort（仅 POSIX）**；在 Windows 上近乎 no-op，**不等于已实现 Windows ACL**。

## 5. 生产化增强项（本阶段挂起）

- **静态加密**：AES-GCM（经 `cryptography`），密钥经环境变量/密钥服务提供（不入库），AAD = `task_id | artifact_id | version | owner_user_id`；或作为替代使用显式 Windows ACL。
- 正式身份认证系统与生产级密钥管理。
- 公网/生产部署。

## 6. 演示场景与验收

唯一强场景（离线、稳定、可重复）：

```text
hr_manager 发起工资汇总任务
→ TaskGraph: s_query(HR, read) → s_report(reporter, read)
→ s_query 产出归属 hr_manager 的 Artifact（虚构员工/模拟工资）
→ s_report 经 ArtifactRef 读取并生成报告（不含工资正文）
→ engineer 尝试读取同一 Artifact → 所有权守卫拒绝
→ 审计日志记录 deny（仅元数据）
```
